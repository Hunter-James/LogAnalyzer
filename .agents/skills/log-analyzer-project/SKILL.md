# Log Analyzer Project

## Начало работы

1. Прочитать корневые AGENTS.md и CLAUDE.md.
2. Проверить git status; не трогать несвязанные изменения и untracked-файлы.
3. Найти существующий путь реализации через rg, затем менять минимальное число модулей.
4. После изменения проверить реальный сценарий, собрать exe и сделать подробный коммит на русском.

## Карта проекта

- src/main.py: запуск Qt, crash-log, обработка файлов из sys.argv.
- src/config.py: дефолты и нормализация settings.json.
- src/gui/window.py: главное окно, восстановление сессии, открытие файлов, применение настроек.
- src/gui/settings.py: диалог настроек; поведенческие параметры возвращаются в MainWindow.
- src/gui/tab_manager.py: группы, панели, вкладки файлов, drag-and-drop и прокрутка.
- src/core/workers.py: чтение .log, .txt, .gz, .zip, .7z, .rar.
- src/core/models.py и src/core/group_stats_worker.py: единая логика партий и сводки группы.
- src/core/file_associations.py: регистрация Log Analyzer как обработчика файлов текущего пользователя Windows.
- LogAnalyzer.spec: однофайловая PyInstaller-сборка с log_perfect.ico.

## Подтвержденные правила поведения

- .log регистрируется как поддерживаемый тип по умолчанию; .zip включается отдельно в настройках.
- Windows 11 не разрешает приложению без участия пользователя назначить default app. Регистрировать ProgID и Capabilities в HKCU, а выбор по умолчанию открывать через ms-settings:defaultapps?registeredAppUser=Log%20Analyzer.
- Путь от Проводника приходит через sys.argv; уже открытый файл нужно активировать, не дублировать.
- Лента групп должна оставлять доступными стрелки прокрутки и кнопку добавления. Колесо над лентой прокручивает группы горизонтально; drag групп сохраняет перестановку.
- Изменения интерфейса групп не должны затрагивать DraggableTabBar файлов.
- Изменения партий должны одинаково применяться в LogModel и GroupStatsWorker.

## Проверка

- Использовать C:\Users\Hunter\AppData\Local\Programs\Python\Python314\python.exe; py может попадать в Windows Store shim.
- Проверять синтаксис измененных Python-файлов через ast.parse.
- Для Qt-компонентов использовать QT_QPA_PLATFORM=offscreen и проверять свойства виджетов и PNG-рендер.
- Выполнять git diff --check.
- Проверять обработку реальных пользовательских файлов, когда они доступны и относятся к задаче.

## Выпуск

1. Закрыть только процессы, запущенные из dist\LogAnalyzer.exe, если они блокируют файл.
2. Собрать dist\LogAnalyzer.exe через LogAnalyzer.spec. При запрете записи sandbox использовать разрешенный запуск PyInstaller вне sandbox с абсолютными путями.
3. Проверить размер, дату и сигнатуру MZ.
4. Выполнить smoke-запуск нового exe и закрыть только созданные тестом процессы.
5. Ставить в индекс только файлы текущей задачи и создавать подробный русский коммит.
